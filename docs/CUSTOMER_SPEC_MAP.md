## מודל הנתונים (14): מה חסר
- **Butcher:** `logo_url`, `cover_url`, `specialty`, `geo`, `opening_hours` מובנה, `suppliers[]`, `sources[]`, `pickup_enabled`, `delivery_enabled`, `delivery_areas[]`, `delivery_pricing`, `status`. קיימים: `slug`, `name`, `description`, `address`, `phone`, `pickup_hours` (טקסט), `city`, `is_test`.
- **Cut:** קיים (`butcher_notes` = `description`, `marbling_manual` = `butcher_marbling`).
- **SaleUnit:** ❌ (ס4).
- **Media:** חסרים `role` (final/process), `approved`, `sale_unit_id`. היום: תמונה ראשית + סדר + וידאו.
- **Cart:** במכשיר בלבד; אין טבלה.
- **ButcherOrder:** חסרים `receive_method`, `delivery_*`, `delivery_fee`, `ready_photo_url`.
- **OrderLine:** חסרים `delivered_weight_g`, `refund_*`, `prep_options`.
- **Reservation, FeedImpression, events:** ❌.

## הצעה לסדר עבודה (בהתאם לסעיף 19, אחרי הכרעה על הסתירות)
1. **שלד:** Header עם סל ותפריט משתמש, ניווט בית/חיפוש, הסרת Live, Categories ו־Auctions, שמירת גלילה.
2. **`CutPost` ופיד:** רכיב אחד, קרוסלה עם וידאו, זמן יחסי, "הוסף לסל" + bottom sheet, `rankFeed()`, פס "נתחים חדשים", טעינה הדרגתית, סוף פיד.
3. **דף קצבייה:** שדות 7.1 (מיגרציה לטבלת קצביות).
4. **חיפוש:** לוגואים, צ'יפים, רשת, טווח יישון.
5. **קופה:** `/checkout` ו־`/orders/:id/confirmation`, אופן קבלה (איסוף; משלוח בנוי וכבוי), שריון זמני.
