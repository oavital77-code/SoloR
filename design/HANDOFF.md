# SoloR — מסירת שפה עיצובית לקוד

התיקייה הזו היא מקור האמת לשפה העיצובית החדשה. היא מחליפה את השפה שנבנתה תוך כדי פיתוח.

## מה יש כאן

| קובץ | מה זה |
| --- | --- |
| `BRAND.md` | ספר המותג: ההחלטות, קול, צבע, טיפוגרפיה, תנועה, צילום, צד הקצב. לקרוא ראשון. |
| `tokens.json` | כל הטוקנים, שתי ערכות: `customer` (כהה) ו־`counter` (בהיר, ממשק הקצב). |
| `tokens.css` | אותם טוקנים כמשתני CSS. `:root` = לקוח, `[data-theme="counter"]` = קצב. |
| `components.css` | מפרט ויזואלי של כל הרכיבים במחלקות `sr-*` (פוסט, חותמת אזל, כפתורים, סל, שריון, ציר זמן, כרטיס הזמנה לקצב). |
| `components/*.md` | הנחיות לכל רכיב: מה מקבל, מתי, מה אסור. |
| `screens/*.html` | 16 מסכי דוגמה כ־HTML סטטי. פותחים בדפדפן כדי לראות איך הכל צריך להיראות. |
| `assets/Logos` | סימן מילים (כהה/בהיר), אייקון אפליקציה 1024, סמל. |
| `assets/Icons` | 16 אייקוני קו (24px, קו 1.5). להטמיע כ־SVG עם `stroke="currentColor"`. |
| `assets/Samples` | איורי נתחים לדוגמה בלבד. כל שימוש מסומן "תמונת דוגמה". |

## סדר עבודה מומלץ

1. **טוקנים.** להכניס את `tokens.css` ל־`globals.css`, ולמפות ב־Tailwind v4 (`@theme inline`) כך שהמחלקות הקיימות ימשיכו לעבוד:
   - `--color-ink: var(--ground)` · `--color-ink-2: var(--surface)` · `--color-ink-3: var(--surface-raised)`
   - `--color-ivory: var(--ink)` · `--color-stone: var(--ink-muted)` · `--color-brand: var(--bordeaux)` · `--color-brand-dark: var(--bordeaux-press)` · `--color-gold: var(--gold)`
   - שימו לב: בקוד הקיים `ink` הוא הרקע; במערכת החדשה `ink` הוא הטקסט. המיפוי למעלה שומר על הקוד הקיים.
2. **פונטים.** דרך `next/font/google`: Frank Ruhl Libre (500–800) ל־`--font-display`, IBM Plex Sans Hebrew (400–700) ל־`--font-sans`, IBM Plex Mono (500–600) ל־`--font-mono`. משקל בסיס 400 (לא 500 כמו היום).
3. **לוגו ואייקון.** להחליף את ה־"SoloR" הטקסטואלי ב־`solor-wordmark-on-dark.svg`. אייקוני PWA ומסך פתיחה מ־`solor-app-icon.svg`.
4. **הפוסט** (`components/Post.md`, `PostStates.md`, `SoldStamp.md`): הסדר בכרטיס, ארבעת המצבים, וחותמת "אזל" החדשה (אליפסה וטרינרית במקום החותמת המוטה הנוכחית).
5. **שאר המסכים** לפי `screens/`: פיד, עמוד נתח, דף קצבייה, חיפוש, סל, קופה, שריון, אישור, מעקב.
6. **ממשק הקצב** עטוף ב־`data-theme="counter"`, לפי `screens/Counter.html` ו־`CounterNew.html`.
7. **טקסטים** חדשים נכנסים ל־`he.ts`, לפי "קול ותוכן" ב־`BRAND.md`.

## כללים שלא לשבור

- מספרים, מחירים, קודים ושעות תמיד LTR מבודדים (`.ltr` הקיים, או `sr-num` / `sr-code`).
- בורדו רק לפעולה הראשית. זהב רק לנגיעות.
- כל מצב (שוריין, אזל, נותרו) מגיע עם מילה, לא רק צבע.
- שטח לחיצה מינימלי 44px ללקוח, 64px לקצב.
- `prefers-reduced-motion` מבטל את נחיתת החותמת.

## מה לא כאן

ערכים בסוגריים מרובעים במסכים (ספקים, כתובות, שעות איסוף) הם מקומות לנתונים אמיתיים. המסכים הם מפרט ויזואלי, לא קוד React: בונים את הרכיבים בקוד ומעתיקים את הערכים.
