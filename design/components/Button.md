# Button

כפתורים: בורדו לפעולה הראשית בלבד, כל השאר שקטים.

- `sr-btn`: פעולה ראשית, גלולה 48px, `shadow-action`. אחת לכל מסך.
- `sr-btn--round`: הוסף לסל בפוסט, עיגול 52px עם `plus`.
- `sr-btn--block`: כפתור תחתון לרוחב המסך בסל, בקופה ובחלון השריון, 52px.
- `sr-btn--ghost` / `sr-btn--quiet`: בחירות (שלם / סטייקים), ביטול.
- מושבת: `surface-raised` ו־`ink-muted`, בלי זוהר. כפתור מושבת תמיד אומר למה (אזל / שוריין).
- פוקוס: קו זהב 2px עם מרווח 3px.
