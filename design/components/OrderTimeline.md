# OrderTimeline

ציר זמן חי לכל קצבייה בהזמנה.

- איסוף: התקבלה ← בהכנה ← מוכנה לאיסוף ← נאספה. משלוח: התקבלה ← בהכנה ← יצאה למשלוח ← נמסרה.
- שלבים שעברו בזהב מלא, השלב הנוכחי בטבעת זהב עם הילה, הבאים ב־`ink-muted`.
- כשמוכנה: צילום המנה מהקצב מופיע מתחת לשלב. חריגת משקל מעל 5% מוצגת כשורה עם ההחזר.
